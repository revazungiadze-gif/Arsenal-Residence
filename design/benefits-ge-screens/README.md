# Benefits.ge — სადაზღვევო CRM პლატფორმა

ჯანმრთელობის დაზღვევის CRM კომპანია **Benefits.ge**-სთვის (გლობალ ბენეფიტს ჯორჯია, GBG ჯგუფის წევრი): რითეილი და კორპორატიული კლიენტები, პოლისები და ლიმიტები, მიმართვა → კლინიკაში ჩაწერა → ვიზიტი → ანაზღაურების სრული ციკლი, AI ასისტენტი და როლებზე დაფუძნებული წვდომა (RLS).

## 📁 რა დევს აქ — 19 ეკრანის დიზაინ-პროტოტიპი

თვითკმარი HTML ფაილები — სერვერი და ინსტალაცია არ სჭირდება, ორმაგი წკაპით იხსნება.

- **`00-avtorizacia.html`** — აქედან დაიწყეთ: მუშა დემო-ლოგინი, როლის მიხედვით გადამისამართებით
- **`_viewer.html`** — ყველა ეკრანი ერთ ნავიგაციან ფანჯარაში
- **`index.html`** — ეკრანების სია
- **`DEMO-USERS.md`** — დემო მომხმარებლები როლებით (6 როლი)

## 🔐 უსაფრთხოების პრინციპები

- წვდომა ბაზის დონეზე (Row Level Security) — არა აპლიკაციის დონეზე
- სამედიცინო მონაცემები ლოგისტიკურისგან გამიჯნულ ცხრილებში
- ყველა წვდომა/ცვლილება audit log-ში
- AI ასისტენტი ბაზას მომხმარებლის სესიით ეკითხება — RLS მასზეც მოქმედებს

> ⚠️ დიზაინის დემო-ლოგინი მხოლოდ პრეზენტაციისთვისაა; წარმოებაში Supabase Auth + MFA.
